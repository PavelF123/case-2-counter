# Кейс-задача № 2. Интерактивный счётчик (Counter)

Веб-приложение на HTML, CSS и Vanilla JavaScript:
- Линейный градиент фона и градиентные кнопки со скруглением `5px`;
- Смена фона окна результата: жёлтый (`> 0`), зелёный (`< 0`), красный (`= 0`);
- Блокировка кнопок при достижении `10` и `-10` и вывод уведомления «вы достигли экстремального значения».

## Запуск
Откройте `index.html` в любом современном браузере.
